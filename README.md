# Örökvirág

Prémium bemutatóoldal kézzel készített szalagvirágok értékesítéséhez.

## Tartalom

- **Bemutató (hero)** — márka, rövid üzenet, CTA
- **Termékek** — válogatott kompozíciók árral és megrendelés gombbal
- **Kapcsolat** — űrlap üzenethez / megrendeléshez

## Futtatás

Nyisd meg az `index.html` fájlt böngészőben, vagy indíts helyi szervert:

```bash
python3 -m http.server 8080
```

Majd látogasd meg: [http://localhost:8080](http://localhost:8080)
